# Inkweld - Home Assistant Add-on

[![Open your Home Assistant instance and show the add add-on repository dialog with a specific repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fbobbyquantum%2Faddon-inkweld)

## About

Inkweld is a collaborative document editing platform with a focus on version control and real-time collaboration.

This repository contains a Home Assistant add-on for Inkweld, allowing you to run and access Inkweld directly from your Home Assistant installation.

## Features

- Real-time collaborative editing
- Version history tracking
- Document organization with folders
- User authentication and permissions
- Image and attachment support
- Fully integrated with Home Assistant

## Installation

1. Click the "Add repository to Home Assistant" button above, or manually add the repository URL to your Home Assistant add-on store.
2. Find the "Inkweld" add-on in the add-on store and click install.
3. Configure the add-on options if needed.
4. Start the add-on.
5. Check the logs to make sure everything is running correctly.
6. Click "OPEN WEB UI" to open the Inkweld interface.
